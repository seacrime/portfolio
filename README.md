# Портфолио — Шилкин Андрей

Моё личное веб-портфолио, созданное для демонстрации навыков, проектов и контактной информации.

## 🌟 Особенности

- Адаптивный дизайн (мобильные устройства, планшеты, ПК)
- Переключение темы (светлая / тёмная)
- Поддержка двух языков (русский / английский)
- Форма обратной связи с клиентской валидацией
- Скачивание резюме в PDF
- Анимированные элементы интерфейса

## 🛠️ Используемые технологии

- HTML
- CSS
- JavaScript
